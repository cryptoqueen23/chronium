Local-first storage

Chronium indexes what you import — file names, extracted text, hashes, provenance — in this browser's local database. Original file bytes stay on your device by default (Local Only mode). Checking "keep a local copy" when importing stores the original bytes in this browser too, so they can be previewed later, but nothing is uploaded to Chronium's servers.

Keyboard & accessibility

  • Open navigation: the menu button in the top bar (mobile), or the sidebar is always visible on wider screens.
  • Close any dialog or menu: Esc
  • All controls are reachable by Tab / Shift+Tab with a visible focus ring.
