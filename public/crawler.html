About ChroniumMind

If you run a website and saw ChroniumMind in your logs, this page explains who we are, what the tool does, and how to ask it to stop or slow down.

What it is

Chronium Mind is a free research tool that helps residents, journalists and students find and read public records, such as meeting agendas and minutes, that governments already publish on the open web. A person starts each search themselves, from a government website's address that they paste in. It is not a search-engine crawler, it does not run on a schedule, and it does not index the web.

How it behaves

Rules the tool follows on every site
RuleWhat it means for your server
It identifies itselfEvery request sends ChroniumMind/0.1 as the User-Agent, with a link to this page.
It reads robots.txt firstIt reads /robots.txt before anything else on your site, obeys Allow and Disallow rules, and follows the group written for ChroniumMind if you have one, otherwise the group for *.
It never goes faster than you askIt obeys Crawl-delay. With no Crawl-delay it waits at least 3 seconds between requests. If a site asks for more than 60 seconds between requests, it does not search that site rather than hurry.
One request at a timeNever in parallel to one site.
It backs offIt honours Retry-After, waits longer after HTTP 429 or 503, and gives up on a site after three such answers in a row.
Small searchesOne search reads at most about 150 pages and 100 documents, and at most 400 requests. A single browser makes at most 500 requests a day to one site.
Public pages onlyIt sends plain GET requests, no cookies, no logins, no forms, no scripts run. It does not try to get around CAPTCHAs, bot protection or access controls: if it is refused, it stops.
Safe addresses onlyIt refuses private, local and internal addresses, and does not follow a redirect to one.
It keeps the source clearFor each document it saves, it records the address, the time it was read and a fingerprint, so anyone can check it against your site. Documents are stored on the person's own device, not republished.

Where requests come from: when a person uses the Chronium Mind extension, requests come from that person's own browser and network. When they use the Chronium Mind website, requests go out from Chronium's server on Cloudflare's network, with the same User-Agent and the same rules, and at most 25 requests per search.

How to ask it to stop, slow down or use something else

Any of these works, and none needs an account:

  • Add this to your robots.txt, and ChroniumMind will not read that part of your site: 
    User-agent: ChroniumMind
Disallow: /
  • Add Crawl-delay: 30 (or any number of seconds) to the same group to slow it down.
  • Tell us what you would prefer, such as a bulk export, a feed or an API, and we will use it instead. Write to: marimercruz8@gmail.com
